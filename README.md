This repository contains the code and reproducible literature-analysis workflow developed for the RILEM TC 315-DCS systematic review, “AI for structural concrete: From material-level information to structural performance across load-bearing capacity, serviceability, and health monitoring.”

The review examines the application of artificial intelligence across three structural-concrete domains: ultimate limit states (ULS) and structural health monitoring (SHM). The workflow supports structured comparison of engineering tasks, structural systems, data sources, dataset sizes, model families, evaluation practices, uncertainty treatment, and interpretability methods.

The repository includes documented notebooks for schema-guided literature extraction, data processing, quality control, and preparation of the review’s tables and figures. Model-generated annotations are treated as preliminary results and require domain-expert validation before inclusion in the final review dataset.
